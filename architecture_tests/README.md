# 舆情风控管理系统 - 体系结构质量属性测试工程

本目录专为软件架构大作业中的**“测试”**环节而建，包含针对本系统三大质量属性（可用性、可修改性、性能）的测试计划、自动化执行脚本以及结果存放规范。本目录的产出物将直接为“体系结构评估”和“写报告”的同学提供工程化的数据支撑。

## 📁 目录结构

```text
architecture_tests/
├── README.md                 # 目录说明文档（本文档）
├── test_plan.md              # 测试计划书：定义了测试范围、场景和期望结果
├── scripts/                  # 可执行的测试脚本存放目录
│   ├── locustfile.py         # 性能测试：Locust 压测脚本
│   ├── test_availability.py  # 可用性测试：Pytest 故障注入脚本（需配合后端代码运行）
│   └── run_modifiability_test.bat # 可修改性测试：自动化分析代码复杂度的批处理脚本
└── results/                  # 测试结果存放目录
    ├── performance/          # 存放性能压测的图表和数据
    ├── availability/         # 存放可用性故障测试的终端截图
    └── modifiability/        # 存放 Radon 静态分析的终端截图
```

## 🚀 如何开始测试？

测试人员（Tester）请按照以下流程推进工作：

1. **阅读计划**：仔细阅读 `test_plan.md`，明确这三个属性到底在测什么。
2. **执行脚本**：进入 `scripts/` 目录，按照脚本内的注释提示，运行性能压测、可用性故障注入和代码复杂度扫描。
3. **收集证据**：将运行成功的终端截图、Locust 导出的数据图表等，归档到 `results/` 下的对应子目录中。
4. **交付结论**：配合“体系结构评估”的同学，将收集到的证据填入最终报告的评估表格中。
