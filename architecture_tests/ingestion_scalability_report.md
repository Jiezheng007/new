# 数据源抓取写入模块 - 吞吐量专项压测

> **测试目的**：验证后端 `POST /api/import/json` 接口在单次接收极大体积 JSON 数据包（即数据洪峰）时的解析与批量落库吞吐能力。

| 数据包体量 (Records/Payload) | 接口响应时间 (ms) | 处理吞吐量 (Records/Sec) | 错误率 / 状态 |
|---|---|---|---|
| 100 条 | 17 ms | 5798 R/s | 正常 |
| 1000 条 | 62 ms | 16119 R/s | 正常 |
| 5000 条 | 239 ms | 20891 R/s | 正常 |
| 10000 条 | 489 ms | 20455 R/s | 正常 |
